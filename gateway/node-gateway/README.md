# WOODFURNI Node Gateway

Express + Socket.IO gateway that:

- Authenticates WebSocket clients via JWT (HS256, same secret as Spring Boot).
- Joins sockets to role-based rooms:
  - `SALES` / `ADMIN` → `admins`
  - `WAREHOUSE` / `ADMIN` → `warehouse`
  - Each CUSTOMER socket is also joined to a `user:<userId>` room.
- Exposes three internal HTTP endpoints protected by a shared secret header (`X-Internal-Secret`). Spring Boot backend calls these to broadcast events:

| Endpoint | Body | Emits to |
|---|---|---|
| `POST /internal/notify/order-created` | `{ orderId, orderNumber, totalAmount }` | `admins` room |
| `POST /internal/notify/order-status` | `{ orderId, orderNumber, status, customerId }` | `user:<customerId>` room |
| `POST /internal/notify/low-stock` | `{ productId, productName, quantityOnHand, threshold }` | `warehouse` room |

WebSocket event names: `order.created`, `order.status.updated`, `inventory.low_stock`.

## Run

```bash
cd gateway/node-gateway
cp .env.example .env   # edit JWT_SECRET to match backend
npm install
npm run dev            # nodemon
# or
npm start
```

Gateway listens on `PORT` (default `3000`).

## WebSocket connection (client side)

```js
import { io } from "socket.io-client";

const socket = io("http://localhost:3000/realtime", {
  auth: { token: "<JWT_ACCESS_TOKEN>" },   // generated by /auth/login
});

socket.on("order.created", payload => console.log(payload));
socket.on("order.status.updated", payload => console.log(payload));
socket.on("inventory.low_stock", payload => console.log(payload));
```

If the JWT is invalid/expired, the socket is rejected and `connect_error` fires.

## Endpoint contract for Spring Boot

```http
POST /internal/notify/order-created
X-Internal-Secret: <INTERNAL_SECRET>
Content-Type: application/json

{ "orderId": "...", "orderNumber": "ORD-20260819-0001", "totalAmount": 1500000 }
```

Same shape for the other two endpoints (see table above).
